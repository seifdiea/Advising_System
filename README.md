# Modified Advising System
## Overview
This project is a **Modified Advising System** that integrates a relational database with a simple
frontend application. The backend is implemented using **SQL Server**, while the frontend is
implemented using **C#** to provide a basic but fully functional user interface.

The project was developed for the **Databases I** course and focuses on correct database design,
SQL implementation, and proper interaction between the database and the application layer.

## Project Milestones (Order: 1 → 2 → 3)

### Milestone 1 – Database Schema Design
- Designed the relational schema for the advising system
- Defined all required tables, attributes, primary keys, and foreign key constraints
- Covered entities such as:
  - Students
  - Advisors
  - Courses
  - Instructors
  - Semesters
  - Graduation Plans
  - Requests
  - Payments and Installments

### Milestone 2 – SQL Implementation
- Implemented the database on **SQL Server**
- Created:
  - Tables
  - Views
  - Stored Procedures
  - Scalar and Table-Valued Functions
- Ensured:
  - Correct data types and constraints
  - Proper joins and data retrieval
  - Enforcement of business rules (e.g., financial status, prerequisites)

### Milestone 3 – Frontend Application (C#)
- Developed a **simple C# frontend** connected to the SQL database
- Implemented required use cases for:
  - Students
  - Advisors
  - Admin
- The UI focuses on correctness and functionality rather than advanced design
- All implemented features are fully functional and correctly reflect database changes

## Technologies Used
- SQL Server
- T-SQL (Views, Stored Procedures, Functions)
- C#
- ADO.NET / Database connectivity
- Windows-based UI (basic forms)

## How to Run

1. Execute the SQL scripts to create and populate the database
2. Open the C# project in Visual Studio
3. Update the database connection string if needed
4. Run the application
5. Use the UI to interact with the advising system

## Notes
- The frontend is intentionally simple
- No advanced UI/UX or optional features are included
- The project prioritizes correctness and compliance with the assignment requirements
